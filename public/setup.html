1Setup code

This stops anyone else who finds the site from setting it up first. In Railway, open your service → Variables and copy SETUP_CODE. If it is not there, open Deployments → View logs and look for the line SETUP CODE:.

2Admin password

Opens /admin, where you create class rooms and can delete every country. Keep it to yourself. At least 16 characters.

3Hall key

Opens a hall room for the whole cohort. Give it to whoever runs the event. At least 8 characters, and different from the admin password.
